# Local map geography

`world-countries-110m.topo.json` is the local 110 m Natural Earth world
topology retained from the repository's ignored Funding reference application.
It excludes Antarctica and uses ISO 3166-1 numeric feature identifiers. The
public Our Outreach explorer converts those identifiers to the canonical
ISO 3166-1 alpha-2 codes stored by Supabase; display names never act as keys.

The geometry derives from the public-domain Natural Earth dataset and the
World Atlas topology format. It contains geography only and does not define or
seed Time&Place Consulting's authoritative country coverage.
